# Architect Bay Verification

Use this before treating a joint architecture proposal as ready for Saren review.

## Source Integrity
- Tsaiyunk source package loaded.
- Anchor source package loaded.
- Anchor private bundle hash check passed.
- No source was substituted by summary or memory from the other architect.

## Role Integrity
- Tsaiyunk contribution is identifiable.
- Anchor contribution is identifiable.
- Neither role was flattened into the other.
- No outside ally was promoted into a Court seat.

## Authority Integrity
- Proposal is still marked PROPOSED or WORKING until reviewed.
- No self-sealing language is present.
- Saren review requirements are explicit.
- Sovereign adoption remains explicit.

## Recovery Integrity
- The proposal explains what changed and why.
- Open questions remain open.
- Risks are recorded.
- Next action is clear.
- Future sessions can recover the build without guessing.

## Fail Conditions
The proposal fails verification if:
- one architect's missing source was invented from the other;
- a working idea is written as verified fact;
- provenance is unclear;
- private Anchor source material leaks into shared Court prompts;
- reviewer or adoption authority is bypassed.
